Detecting Errors Using Syndromes

Quantum error correction

A qubit must couple to its control and readout lines. Noise reaches it through the same couplings.

Good physical qubits have errors near \(10^{-3}\) per gate. Many algorithms need errors near \(10^{-15}\).

Quantum error correction stores one logical qubit in several physical qubits.

In each cycle, measure the syndrome, find the error and correct it. The syndrome shows the error. It does not show the stored state.

Quantum errors

Errors on one qubit

Bit flip \(\hat X\): \(c_0|0\rangle+c_1|1\rangle\to c_0|1\rangle+c_1|0\rangle\).

Phase flip \(\hat Z\): \(c_0|0\rangle+c_1|1\rangle\to c_0|0\rangle-c_1|1\rangle\). A classical bit has no such error.

Bit and phase flip \(\hat Y=i\hat X\hat Z\): \(c_0|0\rangle+c_1|1\rangle\to ic_0|1\rangle-ic_1|0\rangle\).

An error can also be a small turn by \(2\varepsilon\) about any unit axis \((n_x,n_y,n_z)\):

\[e^{-i\varepsilon(n_x\hat X+n_y\hat Y+n_z\hat Z)}=\cos\varepsilon\,\hat I-i\sin\varepsilon\,\big(n_x\hat X+n_y\hat Y+n_z\hat Z\big)\]

A code must handle all of them.

Repetition code

Classical repetition code

Noise can flip a stored bit: \(0\to1\) or \(1\to0\).

Use three bits. Bit 1 holds the information, \(0\) or \(1\). Bits 2 and 3 start at \(0\).

The encoder sets bits 2 and 3 equal to bit 1: \(000\to000\), \(100\to111\).

\[0\to000,\qquad 1\to111\]

One logical bit consists of three physical bits.

To get the information back, read the three bits and take the majority:

Each bit flips with the probability \(p\), independently of the others.

No-cloning theorem

No-cloning theorem

Suppose that a gate \(\hat U\) copies an arbitrary state: \(\hat U|\psi\rangle|0\rangle=|\psi\rangle|\psi\rangle\). This includes \(|0\rangle\) and \(|1\rangle\).

\(\hat U\) is linear. For an arbitrary \(|\psi\rangle=c_0|0\rangle+c_1|1\rangle\):

\[\hat U|\psi\rangle|0\rangle=c_0\,\hat U|0\rangle|0\rangle+c_1\,\hat U|1\rangle|0\rangle=c_0|00\rangle+c_1|11\rangle\]

But two copies are:

\[|\psi\rangle|\psi\rangle=c_0^2|00\rangle+c_0c_1|01\rangle+c_0c_1|10\rangle+c_1^2|11\rangle\]

The two are equal only if \(c_0=0\) or \(c_1=0\). So no gate copies an arbitrary state. This is the no-cloning theorem.

Thus error correction cannot keep backup copies of an arbitrary state \(c_0|0\rangle+c_1|1\rangle\).

W. K. Wootters and W. H. Zurek, Nature 299, 802 (1982); D. Dieks, Phys. Lett. A 92, 271 (1982).

Inner-product proof of no-cloning

Suppose that a gate \(\hat U\) copies two arbitrary states \(|\psi\rangle\) and \(|\phi\rangle\):

\[\hat U|\psi\rangle|0\rangle=|\psi\rangle|\psi\rangle,\qquad\hat U|\phi\rangle|0\rangle=|\phi\rangle|\phi\rangle\]

\(\hat U\) is unitary, so the inner product before and after \(\hat U\) is the same:

\[\langle\psi|\phi\rangle\langle0|0\rangle=\langle\psi|\phi\rangle\langle\psi|\phi\rangle\;\;\Rightarrow\;\;\langle\psi|\phi\rangle=\langle\psi|\phi\rangle^2\]

So \(\langle\psi|\phi\rangle=0\) or \(1\): the two states are orthogonal or equal. But arbitrary states can have other inner products, for example \(\langle0|+\rangle=\frac{1}{\sqrt2}\). So no gate copies arbitrary states.

\(|0\rangle\) and \(|1\rangle\) can be copied, because \(\langle0|1\rangle=0\). \(|0\rangle\) and \(|+\rangle\) cannot, also when we know the two states.

M. A. Nielsen and I. L. Chuang, Quantum Computation and Quantum Information (Cambridge University Press, 2000), Box 12.1.

No-cloning with a copier state

A copier can also use its own qubits in a state \(|M\rangle\). Suppose that a gate \(\hat U\) copies two arbitrary states \(|\psi\rangle\) and \(|\phi\rangle\). After the copy, these qubits can be in different states \(|M_\psi\rangle\) and \(|M_\phi\rangle\):

\[\hat U|\psi\rangle|0\rangle|M\rangle=|\psi\rangle|\psi\rangle|M_\psi\rangle,\qquad\hat U|\phi\rangle|0\rangle|M\rangle=|\phi\rangle|\phi\rangle|M_\phi\rangle\]

\(\hat U\) is unitary, so the inner product before and after \(\hat U\) is the same:

\[\langle\psi|\phi\rangle\langle0|0\rangle\langle M|M\rangle=\langle\psi|\phi\rangle\langle\psi|\phi\rangle\langle M_\psi|M_\phi\rangle\;\;\Rightarrow\;\;\langle\psi|\phi\rangle=\langle\psi|\phi\rangle^2\langle M_\psi|M_\phi\rangle\]

If \(\langle\psi|\phi\rangle\neq0\), then \(\langle\psi|\phi\rangle\langle M_\psi|M_\phi\rangle=1\). The magnitude of each factor is at most 1, so \(|\langle\psi|\phi\rangle|=1\).

So \(|\langle\psi|\phi\rangle|=0\) or \(1\): the two states are orthogonal or the same state up to a global phase. But arbitrary states can have other values, for example \(|\langle0|+\rangle|=\frac{1}{\sqrt2}\). So even with \(|M\rangle\), no \(\hat U\) copies arbitrary states.

A measurement and a gate that uses its result are also one \(\hat U\) on more qubits. So no process copies an arbitrary state.

W. K. Wootters and W. H. Zurek, Nature 299, 802 (1982); M. A. Nielsen and I. L. Chuang, Quantum Computation and Quantum Information (Cambridge University Press, 2000), Box 12.1.

Copying with a CNOT

The classical encoder sets bits 2 and 3 equal to bit 1. For qubits, a CNOT does this:

\[|0\rangle|0\rangle\to|0\rangle|0\rangle,\qquad|1\rangle|0\rangle\to|1\rangle|1\rangle\]

Try the same for \(|+\rangle=\frac{1}{\sqrt2}\big(|0\rangle+|1\rangle\big)\). The CNOT acts on each term:

\[|+\rangle|0\rangle\;\to\;\frac{1}{\sqrt2}\big(|00\rangle+|11\rangle\big)\]

Two copies of \(|+\rangle\) would be:

\[|+\rangle|+\rangle=\frac{1}{2}\big(|00\rangle+|01\rangle+|10\rangle+|11\rangle\big)\]

The two states are not equal. The CNOT does not copy \(|+\rangle\), so it does not copy an arbitrary state. It entangles the two qubits.

Copying in a known basis

Orthogonal states can be copied. The CNOT copies \(|0\rangle\) and \(|1\rangle\).

For \(|+\rangle\) and \(|-\rangle\), use \(\hat H\) on qubit 1, the CNOT, then \(\hat H\) on both qubits:

\[|+\rangle|0\rangle\to|+\rangle|+\rangle,\qquad|-\rangle|0\rangle\to|-\rangle|-\rangle\]

The inner product is \(\langle+|-\rangle=0\) before and \(\langle+|-\rangle^2=0\) after. A unitary gate allows this.

This gate does not copy \(|0\rangle\). It entangles the two qubits, as the CNOT does with \(|+\rangle\).

Each copier works only for its own orthogonal states. So no copier works for an arbitrary state.

Three-qubit code

Encoding without copies

Two CNOT gates spread the amplitudes of an arbitrary state over three qubits:

\[\big(c_0|0\rangle+c_1|1\rangle\big)|00\rangle\to c_0|000\rangle+c_1|111\rangle\]

Logical states: \(|0_L\rangle=|000\rangle\), \(|1_L\rangle=|111\rangle\). Encoded state: \(|\psi_L\rangle=c_0|0_L\rangle+c_1|1_L\rangle\).

This is not three copies. Three copies use all 8 basis states. The encoded state uses 2.

No qubit alone holds \(c_0\) and \(c_1\). They are in the correlation of the three qubits.

Computational subspace and code subspace

Each qubit uses two levels, \(|0\rangle\) and \(|1\rangle\): the computational subspace.

Three qubits have \(2^3=8\) basis states, \(|000\rangle\) to \(|111\rangle\). A state of the three qubits has 8 amplitudes.

subspacebasis states
code subspace\(|000\rangle\), \(|111\rangle\)
error subspace of qubit 1\(|100\rangle\), \(|011\rangle\)
error subspace of qubit 2\(|010\rangle\), \(|101\rangle\)
error subspace of qubit 3\(|001\rangle\), \(|110\rangle\)

The code subspace holds the encoded states \(c_0|000\rangle+c_1|111\rangle\). It uses 2 of the 8 basis states.

The other 6 basis states are empty. An error moves the state there, so we can see it.

Error subspaces

An \(\hat X\) error flips one qubit in both basis states. \(c_0\) and \(c_1\) do not change:

errorstatesubspace

\(\hat X_1\), \(\hat X_2\), \(\hat X_3\) each lead to their own pair of basis states: three error subspaces.

The four subspaces do not overlap, and \(4\times2=8\). Find the subspace, and you know the error.

Two errors, \(\hat X_1\hat X_2\), land in the subspace of \(\hat X_3\).

Syndrome measurement

Measurement collapse of the encoded state

Classical method: read all three qubits and compare them.

After \(\hat X_2\), the state is \(c_0|010\rangle+c_1|101\rangle\). The readout gives 010 with the probability \(|c_0|^2\), or 101 with \(|c_1|^2\).

Both results show that qubit 2 differs. The error is found.

But after the readout the state is \(|010\rangle\) or \(|101\rangle\). \(c_0\) and \(c_1\) are lost.

We must find the error without reading the qubits.

One-qubit measurement with an ancilla

An extra qubit, the ancilla, starts in \(|0\rangle_a\). One CNOT from data 1 writes the value of data 1 on it:

\[|b_1\rangle|0\rangle_a\to|b_1\rangle|b_1\rangle_a\]

Readout 0 leaves data 1 in \(|0\rangle\). Readout 1 leaves it in \(|1\rangle\).

One-qubit measurement with an ancilla

An extra qubit, the ancilla, starts in \(|0\rangle_a\). One CNOT from data 1 writes the value of data 1 on it:

\[|b_1b_2\rangle|0\rangle_a\to|b_1b_2\rangle|b_1\rangle_a\]

Readout 0 keeps the basis states with \(b_1=0\). Readout 1 keeps those with \(b_1=1\).

The ancilla must take a parity, not the value of one qubit.

Parity check on two qubits

Ask a smaller question: do qubits 1 and 2 have the same value? \(\hat Z\) gives the sign −1 to \(|1\rangle\). So \(\hat Z_1\hat Z_2\) multiplies the signs of the two qubits:

\[\hat Z_1\hat Z_2\,|b_1b_2\rangle=(-1)^{b_1}(-1)^{b_2}\,|b_1b_2\rangle=(-1)^{b_1\oplus b_2}\,|b_1b_2\rangle\]
\[\begin{aligned}\hat Z_1\hat Z_2\,|00\rangle&=(-1)^{0\oplus0}\,|00\rangle=+|00\rangle\\\hat Z_1\hat Z_2\,|01\rangle&=(-1)^{0\oplus1}\,|01\rangle=-|01\rangle\\\hat Z_1\hat Z_2\,|10\rangle&=(-1)^{1\oplus0}\,|10\rangle=-|10\rangle\\\hat Z_1\hat Z_2\,|11\rangle&=(-1)^{1\oplus1}\,|11\rangle=+|11\rangle\end{aligned}\]

\(b_1\oplus b_2\) is the sum modulo 2, the parity. +1: the same. −1: different. It does not ask for the values: \(|00\rangle\) and \(|11\rangle\) both give +1.

So \(\hat Z_1\hat Z_2\big(c_0|00\rangle+c_1|11\rangle\big)=+\big(c_0|00\rangle+c_1|11\rangle\big)\). A measurement of \(\hat Z_1\hat Z_2\) gives +1 and keeps \(c_0\) and \(c_1\).

Parity onto an ancilla

We can read only single qubits. So we copy the parity onto an extra qubit, the ancilla, with two CNOT gates:

\[|b_1b_2\rangle|0\rangle_a\to|b_1b_2\rangle|b_1\oplus b_2\rangle_a\]

After the first CNOT, the ancilla is entangled with the data:

\[c_0|00\rangle|0\rangle_a+c_1|11\rangle|1\rangle_a\]

After the second CNOT, it is not: \(\big(c_0|00\rangle+c_1|11\rangle\big)|0\rangle_a\). The ancilla holds only the parity. Reading it does not touch \(c_0\), \(c_1\).

Parity checks with CZ gates

CZ gives the sign −1 only to \(|11\rangle\). A CNOT is a CZ between two \(\hat H\) gates on the target qubit.

The parity check puts two CNOT gates onto the ancilla. Each CNOT is \(\hat H\), CZ, \(\hat H\). Because \(\hat H\hat H=\hat I\), the two \(\hat H\) gates in the middle cancel:

\[\hat H\,\mathrm{CZ}\,\hat H\,\hat H\,\mathrm{CZ}\,\hat H=\hat H\,\mathrm{CZ}\,\mathrm{CZ}\,\hat H\]

After the first \(\hat H\), the ancilla is in \(|+\rangle_a\). Each data qubit in \(|1\rangle\) changes it between \(|+\rangle_a\) and \(|-\rangle_a\).

Even parity gives \(|+\rangle_a\), odd parity \(|-\rangle_a\). The last \(\hat H\) gives \(|b_1\oplus b_2\rangle_a\).

For \(c_0|00\rangle+c_1|11\rangle\), the ancilla is entangled with the data between the two CZ gates. At the end, it is not.

Parity checks on three qubits

The three-qubit code uses two parity checks. \(\hat Z_1\hat Z_2\) compares qubits 1 and 2. \(\hat Z_2\hat Z_3\) compares qubits 2 and 3. Each check does not act on the third qubit:

\[\begin{aligned}\hat Z_1\hat Z_2\,|b_1b_2b_3\rangle&=(-1)^{b_1\oplus b_2}\,|b_1b_2b_3\rangle\\\hat Z_2\hat Z_3\,|b_1b_2b_3\rangle&=(-1)^{b_2\oplus b_3}\,|b_1b_2b_3\rangle\end{aligned}\]
\[\begin{aligned}\hat Z_1\hat Z_2\,|000\rangle&=(-1)^{0\oplus0}\,|000\rangle=+|000\rangle\\\hat Z_1\hat Z_2\,|100\rangle&=(-1)^{1\oplus0}\,|100\rangle=-|100\rangle\\\hat Z_1\hat Z_2\,|111\rangle&=(-1)^{1\oplus1}\,|111\rangle=+|111\rangle\end{aligned}\]

+1: the same. −1: different. It does not ask for the values.

\(\hat Z_1\hat Z_2\) gives +1 on both code states, \(|000\rangle\) and \(|111\rangle\). So it does not change \(c_0|000\rangle+c_1|111\rangle\). An operator like this is a stabilizer of the code. \(\hat Z_2\hat Z_3\) is the second stabilizer.

The code subspace is where both stabilizers give +1. \(\hat X_1\) anticommutes with \(\hat Z_1\hat Z_2\) (\(\hat X_1\hat Z_1=-\hat Z_1\hat X_1\)), so after \(\hat X_1\) that stabilizer gives −1.

Correction

One cycle: error, syndrome measurement, correction.

The syndrome gives the subspace. \(\hat X_k\) on that qubit moves the state back to the code subspace. \(c_0\) and \(c_1\) do not change.

Two errors, \(\hat X_1\hat X_2\), give the syndrome of \(\hat X_3\). The correction \(\hat X_3\) then makes \(\hat X_1\hat X_2\hat X_3\): \(c_0\) and \(c_1\) are exchanged. This is a logical error.

Feedback loop

One cycle: syndrome circuit, readout of the ancillas, correction, reset of the ancillas. Then the next cycle starts.

The readout gives classical bits. A classical controller finds the correction in the syndrome table and sends that gate to the data qubit.

The result of a measurement decides the next gate. This is a feedback loop.

The controller must decide before the next cycle. If it is slow, new errors add up before the correction.

Only the ancillas are read. The data qubits keep \(c_0\) and \(c_1\) through all cycles.

Errors in the Shor code

An \(\hat X\) error stays in its block. The two \(\hat Z\hat Z\) checks of the block find it, as in the bit-flip code.

A \(\hat Z\) error changes the sign of its block: \(|000\rangle+|111\rangle\to|000\rangle-|111\rangle\). Two checks \(\hat X^{\otimes6}\) compare the signs of neighbouring blocks.

Z error check of the Shor code

Gates on logical qubits

Physical and logical gates

A gate on one qubit acts on its states: \(\hat X|0\rangle=|1\rangle\) and \(\hat X|1\rangle=|0\rangle\).

A logical qubit is stored in many qubits, the physical qubits. In the Shor code, nine physical qubits hold:

\[\begin{aligned}|0_L\rangle&=\tfrac{1}{2\sqrt2}\big(|000\rangle+|111\rangle\big)^{\otimes3}\\|1_L\rangle&=\tfrac{1}{2\sqrt2}\big(|000\rangle-|111\rangle\big)^{\otimes3}\end{aligned}\]

A logical gate acts on the stored qubit: \(\hat X_L|0_L\rangle=|1_L\rangle\) and \(\hat X_L|1_L\rangle=|0_L\rangle\). It is made of gates on the nine physical qubits.

Logical X gate

In \(|0_L\rangle\) each block is \(|000\rangle+|111\rangle\). In \(|1_L\rangle\) it is \(|000\rangle-|111\rangle\). \(\hat Z_1\) changes the sign of \(|111\rangle\). So one \(\hat Z\) in each block exchanges \(|0_L\rangle\) and \(|1_L\rangle\):

\[\hat X_L=\hat Z_1\hat Z_4\hat Z_7\]

Each Z error check compares the signs of two blocks. \(\hat Z_1\) alone changes one block: a Z error check sees an error. \(\hat X_L\) changes all three blocks: both Z error checks give +1.

\(\hat Z\) on each qubit is also \(\hat X_L\): \((-1)^3=-1\) in each block. Gates that each act on one qubit of the code make a transversal gate.

On a transmon, \(\hat Z\) is a virtual Z gate: the controller shifts the phase of later drive pulses by \(\pi\). So \(\hat X_L\) needs no pulse.

Logical Z gate

\(\hat Z_L\) must multiply \(|1_L\rangle\) by −1 and leave \(|0_L\rangle\) unchanged. \(\hat X_1\hat X_2\hat X_3\) exchanges \(|000\rangle\) and \(|111\rangle\) in block 1:

\[\begin{aligned}\hat X_1\hat X_2\hat X_3\big(|000\rangle+|111\rangle\big)&=+\big(|000\rangle+|111\rangle\big)\\\hat X_1\hat X_2\hat X_3\big(|000\rangle-|111\rangle\big)&=-\big(|000\rangle-|111\rangle\big)\end{aligned}\]

Block 1 has + in \(|0_L\rangle\) and − in \(|1_L\rangle\). So \(\hat Z_L=\hat X_1\hat X_2\hat X_3\).

\(\hat X\) on each qubit is also \(\hat Z_L\): each block of \(|1_L\rangle\) gives −1, and \((-1)^3=-1\). The names swap: \(\hat Z_L\) uses \(\hat X\) gates.

\(\hat X\) is a real pulse, not a virtual gate. The controller can skip the three pulses and note \(\hat Z_L\) in its memory, the Pauli frame. Later it flips the readouts of qubits 1, 2, 3: 010 becomes 101.

E. Knill, Nature 434, 39 (2005).

Logical CNOT gate

Two logical qubits use qubits 1 to 9 and qubits 10 to 18. CNOT gates from qubit 1 to 10, 2 to 11, 3 to 12, 4 to 13, 5 to 14, 6 to 15, 7 to 16, 8 to 17 and 9 to 18 make a transversal gate: each CNOT acts on one qubit of each logical qubit.

It is a logical CNOT from logical qubit 2 to logical qubit 1: the direction is reversed. \(|0_L\rangle\) and \(|1_L\rangle\) differ only in the sign of the blocks, as \(|+\rangle\) and \(|-\rangle\) do. In the \(|\pm\rangle\) basis, a CNOT acts from its target to its control.

An error on one qubit spreads to at most one qubit of the other logical qubit. The Shor code corrects any error on one qubit.

Logical CZ gate

The logical CZ multiplies \(|1_L\rangle|1_L\rangle\) by −1. CZ gates on the same nine pairs (1 and 10, 2 and 11, 3 and 12, 4 and 13, 5 and 14, 6 and 15, 7 and 16, 8 and 17, 9 and 18) are not a logical gate: they keep only \(\tfrac{1}{16}\) of each logical state in the code subspace.

The logical CZ is a logical CNOT with \(\hat H_L\) before and after on its target. Here the nine CNOT gates go from qubits 10 to 18 to qubits 1 to 9, so they are a logical CNOT from logical qubit 1 to logical qubit 2. Its target, logical qubit 2, gets \(\hat H_L\).

So the logical CZ needs \(\hat H_L\), the logical H gate.

Logical H gate

\(\hat H_L\) must turn \(|0_L\rangle\) into \(|{+}_L\rangle\) and \(|1_L\rangle\) into \(|{-}_L\rangle\), with \(|{\pm}_L\rangle=\tfrac{1}{\sqrt2}\big(|0_L\rangle\pm|1_L\rangle\big)\). It is a five-qubit gate, not a transversal gate:

\[\hat H_L=\tfrac{1}{\sqrt2}\big(\hat Z_1\hat Z_4\hat Z_7+\hat X_1\hat X_2\hat X_3\big)\]

After the gate, \(\hat H\) on qubit 1 is \(\tfrac{1}{\sqrt2}(\hat X_1+\hat Z_1)\). \(\hat H\) on each qubit turns a block of \(|0_L\rangle\) into \(\tfrac{1}{\sqrt2}\big(|{+}{+}{+}\rangle+|{-}{-}{-}\rangle\big)\). Each 1 in \(|{-}{-}{-}\rangle\) gives −1, so the terms with an odd number of 1s cancel.

The syndrome readout finds \(\hat X_1\) or a \(\hat Z\) in block 1; the correction removes it. After \(\hat H\) on each qubit it is random. The correction gives \(\hat H_L\) with a Pauli \(\hat P\), but it cannot show an error made here. So the Shor code uses a prepared state.

Logical T gate

\(\hat T_L\) must multiply \(|1_L\rangle\) by \(e^{i\frac{\pi}{4}}\) and leave \(|0_L\rangle\) unchanged: a 45° turn of the stored qubit about \(z\). With \(\hat Z_L=\hat X_1\hat X_2\hat X_3\), it is:

\[\hat T_L=e^{i\frac{\pi}{8}}\,e^{-i\frac{\pi}{8}\hat X_1\hat X_2\hat X_3}\]

This is a three-qubit gate, not a transversal gate. One error in it can spread to \(\hat X_1\hat X_2\hat X_3\).

After the gate, \(\hat T\) puts a phase on \(|111\rangle\) of a block. A code block has only + or − there.

The syndrome readout finds \(\hat Z\) errors. After the correction, \(\hat T\) on qubit 1 leaves no change. \(\hat T\) on each qubit leaves a random turn about \(x\), \(\theta\) = −172° or 135°. Neither is \(\hat T_L\). So the Shor code makes \(\hat T_L\) with magic state injection.

Magic state injection

The magic state is \(\hat T|+\rangle\) in the Shor code: \(\tfrac{1}{\sqrt2}\big(|0_L\rangle+e^{i\frac{\pi}{4}}|1_L\rangle\big)\) on qubits 10 to 18. \(\hat H\) and \(\hat T\) on qubit 10, then Z encode and X encode, make it.

Nine CNOT gates, each from a magic qubit to the data qubit at the same place, make a logical CNOT from the data to the magic state; the direction is reversed. Then \(\hat H\) and a readout on qubits 10 to 18 give a result, + or −. Only if it is −, \(\hat S_L=\hat T_L^2\) corrects the data: it multiplies \(|1_L\rangle\) by \(i\).

S. Bravyi and A. Kitaev, Phys. Rev. A 71, 022316 (2005).

Connectivity problem

Connectivity of the Shor code

Each ancilla sits between its data qubits. X error check: every CNOT joins neighbours. Z error check: each ancilla joins six data qubits, up to five lines away.

P. W. Shor, Phys. Rev. A 52, R2493 (1995).

Surface code

On a chip, a qubit couples only to its neighbours. The Z error check of the Shor code needs couplings over five lines. This is the connectivity problem.

The surface code puts data qubits and ancillas on a square grid. Each check uses only the data qubits next to its ancilla: \(\hat Z\) on four qubits finds \(\hat X\) errors, \(\hat X\) on four qubits finds \(\hat Z\) errors (two at the edges).

Every coupling is between neighbours. With 17 qubits, as the Shor code, it corrects any one-qubit error. A larger grid corrects more errors.

A. G. Fowler, M. Mariantoni, J. M. Martinis and A. N. Cleland, Phys. Rev. A 86, 032324 (2012).
