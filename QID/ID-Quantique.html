ID Quantique

2025.11.06

ID Quantique（IDQ）是以量子安全加密為核心的瑞士公司，聚焦於量子亂數（QRNG）、量子金鑰分配（QKD）與量子光子偵測器等解決方案。 IonQ 計畫收購 IDQ。



Quantis量子亂數產生器（QRNG）

量子亂數產生（Random Number Generation）：提供「真實量子隨機性」用於高強度金鑰與安全應用。 專為各種使用密碼學或需要不可預測隨機性的應用而設計，利用簡單的光學過程產生真正的隨機性。 提供多種外形規格，從晶片到整機設備皆有，並在成本效益、熵源安全性與可靠性方面通過認證。



Ref: https://www.idquantique.com/random-number-generation/products/

量子密鑰分發QKD系統

▲ IDQ 的 XG 系列是面向企業、政府與電信生產環境的完整量子金鑰分配（QKD）解決方案組合。它提供極致的量子安全性，確保為加密與其他安全裝置提供「可證明安全」的金鑰交換。 XGR 系列則是針對學術界、研究機構與創新實驗室的開放式 QKD 平台。



Ref: https://www.idquantique.com/quantum-safe-security/products/



單光子量子偵測器

IDQ 提供多種偵測器設計：
Standard（標準型）： 採單一 SNSPD，使用線性奈米線蛇形（meander）結構，在系統偵測效率、偵測器雜訊與定時精度上有整體優異表現。亦提供使用螺旋 meander、對偏振不敏感的版本。
Parallel（並聯型）： 多個交錯的 SNSPD 像素並聯於單一讀出線，提供超高速偵測與光子數解析能力。這些偵測器能準確區分多光子態，在某些情境下偵測速率可達 200 Mcps，同時保有 IDQ SNSPD 系列的高效率、高精度、低雜訊與寬頻操作特性。
Multi-Pixel（多像素型）： 多個獨立 SNSPD 像素，各自配備讀出線，提供更快的偵測速率（> 1 Gcps）與對較長脈衝亦具魯棒性的「動態」光子數解析（dynamic PNR），同時延續 IDQ SNSPD 系列在效率、精度、雜訊與寬頻操作方面的優勢。
Ref: https://www.idquantique.com/quantum-detection-systems/products/
