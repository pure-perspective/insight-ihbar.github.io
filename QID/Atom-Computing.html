Atom Computing

Atom Computing, Inc.

2025.10.12

Atom Computing 是一家專注於中性原子陣列之閘基量子電腦的硬體公司，總部位於美國加州柏克萊。以可擴展的原子陣列技術，邁向「邏輯量子位元」時代，並與 Microsoft 展開「量子超級電腦」合作。



技術與研發

▲ Atom Computing的原子陣列示意圖。
Ref: 10.1103/PRXQuantum.6.020334

  • 核心：中性原子架構、大規模可擴展性、長相干時間、最佳化連通性、快速操作、誤差更正導向

  • 架構與材料系統：以光學方式排列與控制中性原子陣列，進行閘型量子計算。

  • 可擴展關鍵指標：大數量且可誤差更正的量子位元、長相干時間、最佳化連通性、快速操作。



產品/服務

  • 定位：通用、閘型量子計算硬體供應商（中性原子架構）

  • AC1000 系統：標榜「1,200+ Fully Connected量子位元」，主打進入「邏輯量子位元」時代。

  • 量子電腦研發與交付：建立可大規模擴展的閘基量子計算平台，聚焦長相干時間、最佳化連結性與高速操作。

  • 策略合作：宣布與 Microsoft 合作，目標打造量子超級電腦。
