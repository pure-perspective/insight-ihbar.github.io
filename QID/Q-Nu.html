QNu Labs

2025.11.06

QNu Labs是印度提供量子密碼學與後量子安全解決方案供應商，聚焦量子金鑰分配（QKD）、量子隨機數（QRNG）、後量子密碼學（PQC），並以平台化（QShield）整合應用。以量子物理提供「真正隨機」、抗竊聽與分散式金鑰能力，協助客戶進入「後量子時代」的資料防護。



Ref: https://www.qnulabs.com/

產品 / 服務

  • QShield 平台：整合 NIST 相容 PQC 演算法、專利 QRNG、QKD 與 API 的「量子安全平台」，並延伸至

    • QConnect / Secure File Sharing：安全檔案分享服務（平台型應用）。

    • QVerse：量子安全訊息服務。

    • Entropy as a Service（EaaS）：以雲端化方式供應高熵隨機性。

  • Armos（QKD）：量子金鑰分配設備，利用單光子傳輸金鑰，能偵測竊聽干擾。

  • Tropos（QRNG）：量子亂數產生器，提供高品質熵源以強化金鑰與各式密碼用途；亦支援 EaaS 供應模式。

  • Hodos（PQC）：後量子密碼套件，標榜「NIST 相容」演算法以因應量子計算威脅。



Tropos 量子隨機數產生器（QRNG）

▲ Tropos - Quantum Random Number Generator (QRNG)
Ref: https://www.qnulabs.com/

Tropos 的隨機性源自「雷射量子來源」。雷射會產生一串光子。系統以「單光子到達時間（Time-of-Arrival）」為依據：量測單光子抵達單光子探測器（SPD）的時間，把這些不可預知的到達時間轉換為隨機數。



▲ 從光子產生到輸出隨機數的流程：雷射先發出光，再經由可變光學衰減器（VOA）把強度調整到單光子等級。接著，光子被送往 SPD（Single Photon Detector）；系統以外部時間基準記錄每一次偵測所落入的時間分箱（time bin）。
Ref: https://www.qnulabs.com/

對於每一個時間分箱，光子落入其中的機率是均勻的。即使你事先完全知道態的制備、傳播與偵測等所有參數，也無法預先確定實際會落在哪一個時間分箱；只有在偵測那一瞬間，光子的量子態才會坍縮到某個特定的時間分箱。

系統會以測試套件檢驗所產生位元的隨機性。只有在通過檢驗的情況下，這些位元才會被轉送給需要隨機數的應用或使用者。對外傳輸通常採用 RESTful 介面作為 API，將 Tropos 的隨機數提供給外部應用或終端使用者。



技術與研發

  • QKD 技術要點：單光子/量子態擾動可偵測竊聽，適合高價值通道的金鑰配送。

  • QRNG：以量子物理來源提供「本體隨機性」（ontic randomness），可顯著降低傳統偽隨機的模式風險。

  • PQC：平台宣稱「NIST 相容」。

  • 平台整合：以 API 將 QKD/QRNG/PQC 接入現有堆疊（TLS/IPsec、VPN、儲存加密、KMS/HSM），支援「混合密碼」（PQC+傳統）與「混合分配」（QKD+PQC）遷移路線。
